# wild6-ericdarling-glitch.github.io

The Wild 6 marketing website, served via GitHub Pages.

- `/images` also doubles as public image hosting for Wild 6 HTML email signatures. Don't rename or remove existing files in that folder without checking whether they're still linked from a sent email signature.
- `/assets` holds the site's CSS, JS, and favicon files.
- Page content lives in the root-level `.html` files (`index.html`, `services.html`, `about.html`, `contact.html`, `privacy-policy.html`, `terms-conditions.html`).
